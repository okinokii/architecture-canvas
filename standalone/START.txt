Architecture Canvas — офлайн-редактор архитектурных схем.

ЗАПУСК
1. Распакуйте архив в любую папку.
2. Откройте index.html двойным кликом в Chrome или Edge. Интернет не нужен.
3. Рисуйте схему: блоки перетаскиваются с панели, связи редактируются двойным кликом.
4. Меню «Экспорт» сохраняет PNG, JSON, Mermaid и запрос для ИИ.
5. Меню «Справка» открывает инструкцию и ссылки на проект.

Схема автосохраняется в этом браузере. Для другого браузера или устройства
сохраните JSON через «Файл → Сохранить JSON» и откройте его через «Файл → Открыть JSON».
